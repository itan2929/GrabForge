GrabForge

映像・音声の取得と、音声の仕上げをひとつのアプリで。

はじめる

  1. フォルダー全体を展開し、GrabForge.exe を起動します。
  2. 「ツール・更新」から「まとめて準備 / 更新」を実行します。
  3. URLを解析し、形式と保存先を選んでキューに追加します。

フォルダーの役割

  • GrabForge.exe — 起動するファイル
  • app — アプリ本体。中のファイルはまとめて保管してください。
  • data — 設定・プリセット・履歴・取得したツール・更新バックアップ
  • downloads — 標準の保存先。アプリから変更できます。

移動するときはフォルダー全体を移してください。旧版の tools フォルダーも引き続き利用できます。旧版からの更新で残った内部ファイルは data/backups へ退避します。
