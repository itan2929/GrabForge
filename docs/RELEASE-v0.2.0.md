# GrabForge v0.2.0

画面とブランドを整えたリリースです。

- 新しいロゴと、Windows用マルチサイズアイコンを追加。
- ダウンロード画面を左右に分割。形式選択とタブ式設定を同じ画面へ配置。
- コンプレッサーと正規化を横並びにし、それぞれの「かんたん／詳細」を維持。
- 長い常設説明を減らし、ラベル・操作・短い状態表示を中心に整理。
- READMEを刷新し、クイックスタート・実画面・開発手順を掲載。
- 旧名称をソースと内部処理から整理し、旧ビルドを現在の作業・配布対象から分離。
- コーデック情報がない形式も選択可能にし、非表示タブの入力エラーも保持。

更新ヘルパーに不具合が見つかったため、v0.2.1以降を使用してください。v0.1.0/v0.2.0からは、アプリを終了して修正版ZIP全体を同じフォルダへ上書き展開してください。設定・プリセット・履歴と導入済みツールは保持します。

新規利用はWindows x64向けZIPを全体展開し、`GrabForge.exe`を起動してください。初回は「ツール・更新」→「まとめて準備 / 更新」を実行します。
