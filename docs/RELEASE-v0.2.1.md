# GrabForge v0.2.1

v0.2の画面・ブランド改善と、更新ヘルパーの修正を含む配布版です。

- 新しいロゴとWindows用マルチサイズアイコン。
- 左右分割とタブ式設定で、長い縦スクロールを解消。
- コンプ・正規化を横並びに配置し、常設の説明文を削減。
- 実画面、クイックスタート、開発手順を含むREADMEへ刷新。
- 旧名称を現行ソース・内部マーカー・配布物から整理。
- 更新先パスの末尾区切り文字で更新ヘルパーが停止する不具合を修正し、回帰テストを追加。

## 旧版からの更新

**v0.1.0/v0.2.0からは、アプリを終了し、このZIP全体を同じフォルダへ上書き展開してください。** 旧ヘルパー自体に不具合があるため、一度手動での更新が必要です。更新が停止した場合は、タスクマネージャーで`GrabForge.Updater.exe`を終了してから展開します。

ZIPには`data/`と`tools/`を含めないため、設定・プリセット・履歴・導入済みツールは保持できます。v0.2.1以降の更新ヘルパーには修正を適用済みです。
