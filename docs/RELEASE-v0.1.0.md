# GrabForge v0.1.0

Windows向けのネイティブなyt-dlp / FFmpeg GUIです。ZIP全体を展開し、`GrabForge.exe`を起動してください。.NETは同梱済みで、Python・Node.js・ブラウザは不要です。

- 映像と音声の個別選択、動画＋音声／音声のみ／動画のみ
- 保存形式、サンプリング周波数、CBR/VBR・ビットレート
- コンプレッサーと2パス正規化、それぞれ「かんたん／詳細」設定
- 字幕・画像・チャプター、プレイリスト、キュー制御と履歴
- 全設定を保存するプリセットとJSON入出力
- yt-dlp・FFmpeg・Denoの取得／更新、本体のリリース検知とポータブル更新

初回は「ツール・更新」の「必要なツールをまとめて準備 / 更新」を押してください。外部ツールの取得にはネット接続が必要です。設定・履歴・プリセットは`data/`、ツールは`tools/`へ保存し、PCのPATHは変更しません。

対象はWindows x64です。署名は付いていません。対応形式や認証の要否はサイトに依存します。字幕・画像・チャプターの対応範囲は保存コンテナに依存し、音声変換と加工の併用で2回エンコードする場合があります。

26単体テスト、実際の音量測定・映像ハッシュ維持、字幕／画像／分割の組み合わせ、キュー制御、設定保持、更新／復元を検証しました。詳細は`docs/ACCEPTANCE.md`をご覧ください。
